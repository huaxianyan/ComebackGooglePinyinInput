## 注册来源、创建通道与缓存失效

- 原 Java 默认数据类型依次为 24、24、23、24，字典类型为 3、3、2、3，按新词、联系人、用户词典、快捷短语排列。注册使用私有文件 FD、零 offset 和转 int 的文件长度。文件缺失、IOException 或 FD 注册失败时，显式改为空注册。具体模型加载失败后的处理由后续取证补充，不只按 Java 分支推断。
