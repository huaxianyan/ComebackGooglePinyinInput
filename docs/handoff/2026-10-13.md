## 2026-10-13 第四轮：截图区居中流排

- 固定 270 px 的裸连排被用户否掉：竖图被渲染成独立段落，一张一行叠成高塔，太占空间。
- 调研了 8 个贴实机截图的仓库。机制结论：img 之间隔空行会渲染成独立段落逐张竖排；同段连续 img 才横向流排；宽度百分比在窄屏自动降级，定长 px 会回退竖排。Material Files 的 `width="32%"` 加段落包裹是最稳形态，NewPipe 的 160 px 固定值窄屏表现差，不取。
- 定形：`<p align="center">` 包裹全部截图，img 连续写无空行，统一 `width="32%"`，宽屏一行三张。readme-standard 同步此定形。
- 本轮只动 README 截图区，未触及代码与其他文档。
