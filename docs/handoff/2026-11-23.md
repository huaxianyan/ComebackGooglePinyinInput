## 发现的缺陷：条目级快照停在 11-15

`files/dictionary-safety/` 里三份 `snapshot-*.txt.gz` 全部停在 11-15，而文件级副本
`file-*.gz` 一直更新到 11-23 15:00。

原因链：

1. 原生引擎把删除过的词留成权重 0 的墓碑（11-11 记录已确认这条语义）。
2. `GoogleNativeDictionaryBridge.canonicalEntry()` 只过滤单字，不过滤 `count <= 0`，
   墓碑因此进了 `read()` 的条目列表。
3. 快照写出 `词\t拼音\t0`，`DictionarySafetySnapshot.parse()` 的 `count <= 0`
   判据把整份视为无效。
4. `DictionarySafetyStore.write()` 写完读回校验，`verified == null` 就删掉新文件并
   静默返回，不写 note、不动 `last_debug`，所以状态页全程是绿的。

取证：

- 单独编译 `DictionarySafetySnapshot` 跑：健康快照 `ok entries=2`，含墓碑的快照 `null`。
- 扫 12 份导出备份，「多字且权重 ≤0」的条目数 11-11 至 11-15 为 0，11-16 起
  1（叶惠美）、1、2、2、10、11、16，与快照停在 11-15 16:25 对得上。
- 11-15 那份快照头部 100,310、`END 99986`，差值是单字被过滤，属既有设计。

影响：条目级兜底只能恢复到 11-15 的 99,986 条，而这条防线专门用来救「文件完整但
引擎只读一小部分」的逻辑塌陷，文件级兜底判的是文件变小，对那种情况不触发。

## 修复

`canonicalEntry()` 在单字过滤之后加一条 `if (source.count <= 0) return null;`，
与 `DictionaryBackupText` 第 64 行、`Change` 的既有约束对齐。墓碑本来就恢复不回来，
留着只会让整份快照作废。

- `scripts/generate_rime_sync_smali.py` 重新生成，smali 差异除新逻辑外只有 `.line` 偏移。
- `scripts/generate_dictsafety_smali.py` 重跑后产物无变化。
- `scripts/test_rime_sync_protocol.py` 通过。该门禁要求 `decoded` 目录与补丁产物一致，
  `work/decoded` 是旧的补丁后状态会误报，需要重新解码原始 APK 再 apply。

顺手修掉两个让 CI 长期变红的门禁问题（与本次缺陷无关，之前一直没暴露）：

- `docs/DICTSAFETY.md` 列表项以分号收尾，中文文案门禁从 `f70223a` 起一直报这条。
- `scripts/verify_chinese_copywriting.py` 把带中文的错误行 print 到 cp1252 的 stdout，
  抛 `UnicodeEncodeError` 盖掉真正原因，CI 只看到一排编码栈。已在启动时把
  stdout 改到 UTF-8。
- 构建还要求 `docs/releases/v<版本>.md` 存在，缺了会停在「Prepare versioned release body」。

## 同日：悬浮键盘阶段 1

阶段 1 的目标是「窄卡片 + 触摸区域」，也就是 issue 抱怨的「太大」本身。

- 开关进「外观与布局」，键名与 `FloatingKeyboardCompat` 对齐（独立文件 `floating_keyboard_preferences`）。
  开启时把单手模式置 0，反过来选单手模式也会关掉悬浮，两者抢同一份 insets。
- 默认关闭。平板默认开启要等阶段 2 的拖动和阶段 3 的缩放补齐，否则平板用户只会得到一个挪不动的卡片。
- 缩放走 `setScaleX/Y` 加 `pivotY = height` 的视图变换，不缩容器。原生键行从主题取固定高度，
  只缩宽度会得到窄而高的畸形按键，而且变换后触摸坐标由框架反变换，不用自己算。
- `getBoundsOnScreen` 是隐藏 API，编译期就找不到符号，改用 `getGlobalVisibleRect`。
  手算矩形会把缩放偏移重复加一次，实测直接算到屏幕外。
- 关闭分支要把缩放还原成 1，只还原 insets 会让视图缩着、布局按全宽算，错位。

Pixel 10 Pro / Android 17 实测（平板模拟 `1600x2560` @ 320 dpi，`scale=0.72`）：

- 单元格几何 `region=[224,1779][1376,2265]`，居中贴底，应用内容全屏不被压缩。
- 按键、候选栏、空格、`?123` 全部可点，点键出字正常。
- 关掉开关后键盘恢复全宽停靠，日志里 `FloatingKeyboard` 记录归零。
