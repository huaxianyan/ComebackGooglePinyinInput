## 补充：只影响下一词预测的可行性（同日追加）

### 完成

- 复核 `adw.a(JLchw;)Z` 退格分支，修正文档里写反的伪码。真正判据是「解码结果无候选 `chk`(tag 2) 且无标点 `chh`(tag 3)」时，`cgp.h == false` 无条件挂起；`cgp.h == true` 时联想要非空 `azh.a() == true` 才挂起。
- 确认四个英文 IME 定义（含 `ime_en_9key`）都把该开关写成 `true`，两个 hard qwerty 定义缺条目，走默认 `false` 的无条件挂起档。
- 核实 `next_word_prediction` 只被读一次（`LatinIme.smali` 第 913 至 923 行）→ `cgp.c` tag 3，不参与自动空格与自动大写的启用条件。
- 核实补全钩子拿不到清空 `azh` 的 API：`azh.b()V` 私有，`azh.a()V` 只重置游标，`Layx.a()V`/`Layv.a()V`/`textCandidatesUpdated`/`finishComposingText` 都是向外通知。

### 结论

- 有办法只影响下一词预测：关 `next_word_prediction`。代价是普通输入的下一词预测一并停用，且它是全局设置，没有符号级粒度。
- 「只让符号不引发预测」在现有钩子里做不成，需要改解码判据或让英文路径的符号也走一次解码。

### 边界

- 仍未改功能代码，仅调研与文档，`verify_chinese_copywriting.py` 通过。
