当前 target API 兼容阶段的最终正式版本，基于 Google 拼音输入法 4.5.2，保留原有输入体验并完成 Android 16/17 兼容维护、原生剪贴板候选、首次使用流程、词库持久化恢复、本地灾难备份和按需词库健康状态。

## 主要更新

- **Android 16/17 兼容维护**：完成当前 API 阶段的兼容工作，应用内显示名称保持「Google 拼音输入法」。
- **原生剪贴板候选与首次使用流程**：保留原生候选体验，并提供完整的一次性引导。
- **词库持久化恢复与本地灾难备份**：增加可变词库的恢复层，以及基于 Storage Access Framework 的本地备份。
- **按需词库健康状态**：在设置中按需查看词库可读取性，不扫描词典正文。
