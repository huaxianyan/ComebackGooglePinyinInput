保留 Google 拼音原有输入体验，增加剪贴板快捷粘贴、首次引导和用户词典备份恢复能力。

## 新功能

- **剪贴板候选**：候选栏提供剪贴板快捷粘贴，保留原生候选交互。
- **首次引导**：提供启用、选择输入法和完成的一次性引导。
- **词典备份与恢复**：增加持久化恢复层、本地备份和按需词库健康状态。

## 改进

- **现代 Android 兼容**：适配导航栏、触摸和手写等既有行为，正式版本保持 target SDK 28。
