本版本为普通中文软键盘增加原生简体/繁体中文快速切换，并提供可选的 Header 入口显示开关。切换继续使用 Google 拼音原有中文 HMM 键盘状态链路，因此当前输入、Candidate 和设置页状态会同步刷新。

## 主要更新

- **快速切换简繁中文**：中文拼音 QWERTY、中文拼音 9 键和中文笔画键盘在语音或收起键左侧显示「简/繁」按钮。
- **复用原生转换状态**：点击发送原始 `KEYBOARD_STATE_ON/OFF + ENABLE_SC_TC_CONVERSION` 事件，不自行转换输入文本，也不绕过原有 HMM、Candidate 和 Preference 同步逻辑。
- **可关闭额外入口**：在「键盘 → 按键」中新增「显示简繁切换按钮」，紧跟「显示语音输入按钮」，默认开启。关闭入口不会改变当前简繁模式。
- **保留现有 Header 功能**：不替换 Access Points、主题入口、语言标签、语音输入或收起键，原有 voice/`NO_MICROPHONE` hide-keyboard 映射保持不变。
- **自动避免空间冲突**：空间不足时快捷按钮安全隐藏，不缩小或覆盖既有触摸目标。Access Points 展开时，「简/繁」与「中/EN」同步隐藏，收起后自动恢复。
- **保持 Candidate 与填充链路**：普通 Candidate、敏感 Clipboard 候选和 Inline Autofill 继续按既有 Header Platform 优先级与数据语义运行。
