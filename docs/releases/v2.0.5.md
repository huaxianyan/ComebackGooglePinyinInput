# Google 拼音输入法 2.0.5

本版本为普通中文软键盘增加原生简体/繁体中文快速切换，并提供可选的 Header 入口显示开关。切换继续使用 Google 拼音原有中文 HMM 键盘状态链路，因此当前输入、Candidate 和设置页状态会同步刷新。

## 主要更新

- **快速切换简繁中文**：中文拼音 QWERTY、中文拼音 9 键和中文笔画键盘在语音或收起键左侧显示「简/繁」按钮。
- **复用原生转换状态**：点击发送原始 `KEYBOARD_STATE_ON/OFF + ENABLE_SC_TC_CONVERSION` 事件，不自行转换输入文本，也不绕过原有 HMM、Candidate 和 Preference 同步逻辑。
- **可关闭额外入口**：在「键盘 → 按键」中新增「显示简繁切换按钮」，紧跟「显示语音输入按钮」，默认开启。关闭入口不会改变当前简繁模式。
- **保留现有 Header 功能**：不替换 Access Points、主题入口、语言标签、语音输入或收起键，原有 voice/`NO_MICROPHONE` hide-keyboard 映射保持不变。
- **自动避免空间冲突**：空间不足时快捷按钮安全隐藏，不缩小或覆盖既有触摸目标。Access Points 展开时，「简/繁」与「中/EN」同步隐藏，收起后自动恢复。
- **保持 Candidate 与填充链路**：普通 Candidate、敏感 Clipboard 候选和 Inline Autofill 继续按既有 Header Platform 优先级与数据语义运行。

## 设置与兼容范围

新设置同时支持：

```text
Android 4.2–14 / API 17–34 → legacy Preference
Android 15+ / API 35+      → Compose Material 3
```

快捷按钮首版仅显示在明确支持的普通中文软键盘：

```text
中文拼音 QWERTY
中文拼音 9 键
中文笔画
```

英文、手写、符号、Emoji、密码、数字、PIN、电话、日期时间及硬键盘路径保持原样，不显示该入口。

## 真机验收

Pixel 10 Pro / Android 16 上完成验收：

- 点击「简/繁」后实际中文输入和 Candidate 即时变化
- 原设置中的「繁体中文」开关同步变化
- 新增显示开关即时隐藏和恢复快捷按钮，不改变当前模式
- voice/hide-keyboard 状态与位置正常
- Candidate、Clipboard 和 Inline Autofill 运行正常
- Access Points 展开时，快捷按钮与「中/EN」同步隐藏，第四个 Access Point 没有重叠，收起后正确恢复

完整构建继续通过：

- 从原始 APK 开始的可复现补丁与 Compose Material 3 Host 重建
- 6,633 个旧公开资源 ID 保持
- API 31、33、34、35、36 静态门禁
- Header Platform、Inline Autofill 及敏感 Clipboard 门禁
- legacy primary DEX 与 Compose/AndroidX 隔离
- APK v1/v2/v3 签名与 16 KiB ZIP alignment

## 兼容边界

- 快捷按钮只改变 Google 拼音的简繁输出状态，不对已提交文本进行转换。
- 空间或当前 Header 身份不明确时会隐藏入口，而不是压缩或覆盖现有按键。
- APK 仅提供 `arm64-v8a` 架构。
