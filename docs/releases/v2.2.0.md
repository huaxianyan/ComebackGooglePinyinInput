本版本给键盘底部行的逗号键和句号键各加了一个显示开关，位于「键盘 → 按键」，中文与英文键盘都提供。关闭后该键让出空间，由空格键相应变宽，其余按键宽度不变。这是隐藏按钮，不是把逗号和句号交换，也不是双空格输入句号。Google 拼音原有的输入、候选、学习、手写、主题和分页行为保持不变。

## 主要更新

- **逗号键、句号键各有一个显示开关**：开关默认开启，关闭后对应按键从底部行消失，空格键占用其宽度。中文底部行与英文底部行都支持，手机与平板两套布局同步生效。
- **只让出空间，不改字符**：底部行标点槽位改由键盘状态位驱动 `keymapping`，开关开启时保持原生标点键，关闭时映射到 `softkey_empty` 并退出布局。
- **其余按键宽度不变**：新增 `CommaPeriodToggleKeyView` 在运行时把隐藏槽位释放的权重加给空格键，空格容器与语言切换键、确认键宽度保持不变。
- **网址与邮箱输入框不受影响**：这两类输入框里逗号、句号位置本就是 `/`、`@`、`.com`，开关不改变它们的映射。

## 已知行为说明

底部行逗号键兼任长按进入表情的入口。关闭逗号键后该入口一并消失，这是隐藏按键的预期结果。仍需要长按进表情时，保持逗号键开启即可。
