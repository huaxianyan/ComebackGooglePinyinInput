# Google 拼音输入法 2.0.0

本版本是 Android 16 / target SDK 36 正式兼容基线，汇总并固化了从 Android 10 到 Android 16 逐级完成的 target SDK 29–36 兼容工作。正式包名和签名身份保持不变，原生输入、候选、学习、词典、手写、主题、触摸和备份语义保持不变。

## 主要更新

- **Android 16 / target SDK 36**：正式版本升级到 target SDK 36，并将逐级验收的 Android 10–16 兼容实现合并为后续开发的稳定基线。
- **covering-IME 几何模型**：IME Window 和底部主题视觉延伸至显示底部，原生按键、候选和手写交互区域仍截止于系统导航区域上方，导航控件继续由 SystemUI 管理。
- **导航与主题一致性**：同时适配三按钮和手势导航，底部视觉面跟随内置主题、图片主题、动态导航高度和键盘高度变化，不硬编码设备像素，也不扩大原生触摸区域。
- **Android 12–16 安全门禁**：补齐组件 `android:exported`、PendingIntent mutability、动态 receiver 等平台要求，并拒绝无用途的通知、媒体权限和推测性兼容补丁。
- **隔离审计机制**：Debug 和诊断能力只能用于隔离 application ID。正式包保持 release-like、非 debuggable，诊断不采集输入、剪贴板、联系人或词典正文。
- **可复现发布基线**：GitHub Actions 校验正式包名、版本、target SDK、签名身份和构建摘要，避免测试包或目标版本不符的产物进入正式 Release。
