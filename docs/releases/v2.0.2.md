# Google 拼音输入法 2.0.2

本版本主要为所有相关键盘建立统一的原生 Header 候选区域，并为敏感剪贴板内容及密码/PIN 输入目标提供安全的脱敏候选粘贴。原生输入、候选、学习、词典、手写、主题、分页、触摸和备份语义保持不变。

## 主要更新

- **统一键盘 Header**：文本密码、Web 密码、可见密码、数字密码/PIN、普通数字、电话和日期时间键盘现在都具备独立的原生 Header，候选内容不会替换数字键、QWERTY、符号、删除、空格或 IME action 等必需输入键。
- **保持原生候选体验**：所有目标键盘共用 `FixedSizeCandidatesHolderView` 和原生 Candidate 控制器，继续跟随当前键盘主题、原生分隔符、关闭按钮、点击反馈和无障碍行为。电话键盘仍保留 `DialKeyboard` 的专用逻辑。
- **敏感剪贴板脱敏**：当剪贴板来源使用 Android 标准敏感标记，或目标输入框为文本/Web/数字密码时，候选以最多 32 个圆点显示，但点击后仍提交完整原始内容。
- **敏感数据分离**：敏感明文不会进入候选显示文本、TalkBack 文本、Candidate tag、去重键、日志或持久化，显示、无障碍说明、完整 payload 和关闭身份相互分离。
- **手机与平板一致支持**：统一覆盖相关手机资源和 `sw600dp` 平板资源，为后续通过 Android 标准 Inline Suggestions 协议接入 Autofill 建立稳定承载区域。
