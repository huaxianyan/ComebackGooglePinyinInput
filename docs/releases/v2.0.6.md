# Google 拼音输入法 2.0.6

本版本修复候选面板展开和收起动画在高刷新率屏幕上仍被稳定按 60fps 调度的问题。Android 16/API 36及以上只在原生动画实际运动期间请求系统高刷新率类别，动画结束或取消后立即释放，不让输入法在空闲时持续保持高刷。

## 主要更新

- **候选面板动画更流畅**：展开和收起继续使用原版 80ms `translationY`动画，不修改时长、插值、布局或触摸语义；Pixel 10 Pro上活动帧间隔由约16.67ms降至约8.34ms。
- **按动画生命周期动态高刷**：动画开始时请求 Android公开的 high frame-rate category，结束、取消或反向切换时恢复 `NO_PREFERENCE`。
- **不固定具体刷新率**：不写死120Hz，不设置 Window `preferredRefreshRate`，不启用全局 touch boost；实际刷新率继续由Android结合屏幕能力、温度、功耗和系统策略决定。
- **保持旧系统兼容**：API 36-only调用通过精确兼容桥隔离，API 17–35保持原行为，legacy primary DEX不直接解析新方法。
- **不改变输入语义**：Candidate数据、提交、学习、词典、分页、主题、Clipboard、Inline Autofill、简繁切换和无障碍语义保持不变。

## 诊断与真机验收

无功能差异的 Debug基线确认：

```text
显示能力：120Hz
旧 IME Surface调度：60Hz
活动帧间隔：约16.67ms
FrameTimeline jank：0
Thermal Status：0
```

这证明问题不是 CPU、GPU、layout/draw、GC或热节流，而是刷新率分类。完成最小修复后，release-like、non-debuggable隔离包在 Pixel 10 Pro / Android 16上得到：

```text
活动帧间隔中位数：8.341ms
7–10ms活动间隔：100
15–19ms活动间隔：0
现代 gfxinfo jank：0
Missed Vsync：0
Slow UI thread：0
Thermal Status：0
```

动画期间 IME UID实际获得120Hz override；静止后该 override消失并回落到系统默认调度。用户真机主观验收为“明显更流畅”。未发现 `VerifyError`、应用崩溃或异常退出。

## 构建与兼容范围

完整构建继续通过：

- 从固定原始 APK开始的可复现补丁与 Compose Material 3 Host重建；
- 6,633个旧公开资源 ID保持；
- API 31、33、34、35、36静态门禁；
- legacy primary DEX与 API 36-only调用隔离；
- Header Platform、Inline Autofill和敏感 Clipboard门禁；
- APK v1/v2/v3签名与16 KiB ZIP alignment。

兼容边界：

- 动态高刷提示仅在 Android 16/API 36及以上生效；Android 15及以下行为不变。
- 系统可因省电模式、温度、设备刷新率能力或厂商策略降低或拒绝高刷请求。
- APK仅提供 `arm64-v8a`架构。
