# Google 拼音输入法 2.0.6

本版本修复候选面板展开和收起动画在高刷新率屏幕上仍被稳定按 60 fps 调度的问题。Android 16/API 36 及以上只在原生动画实际运动期间请求系统高刷新率类别，动画结束或取消后立即释放，不让输入法在空闲时持续保持高刷。

## 主要更新

- **候选面板动画更流畅**：展开和收起继续使用原版 80 ms `translationY` 动画，不修改时长、插值、布局或触摸语义。Pixel 10 Pro 上的活动帧间隔由约 16.67 ms 降至约 8.34 ms。
- **按动画生命周期动态高刷**：动画开始时请求 Android 公开的 high frame-rate category，结束、取消或反向切换时恢复 `NO_PREFERENCE`。
- **不固定具体刷新率**：不写死 120 Hz，不设置 Window `preferredRefreshRate`，也不启用全局 touch boost，实际刷新率继续由 Android 根据屏幕能力、温度、功耗和系统策略决定。
- **保持旧系统兼容**：API 36-only 调用通过精确兼容桥隔离，API 17–35 保持原行为，legacy primary DEX 不直接解析新方法。
- **不改变输入语义**：Candidate 数据、提交、学习、词典、分页、主题、Clipboard、Inline Autofill、简繁切换和无障碍语义保持不变。

## 诊断与真机验收

无功能差异的 Debug 基线确认：

```text
显示能力：120 Hz
旧 IME Surface 调度：60 Hz
活动帧间隔：约 16.67 ms
FrameTimeline jank：0
Thermal Status：0
```

这证明问题不是 CPU、GPU、layout/draw、GC 或热节流，而是刷新率分类。完成最小修复后，release-like、non-debuggable 隔离包在 Pixel 10 Pro / Android 16 上得到：

```text
活动帧间隔中位数：8.341ms
7–10 ms 活动间隔：100
15–19 ms 活动间隔：0
现代 gfxinfo jank：0
Missed Vsync：0
Slow UI thread：0
Thermal Status：0
```

动画期间，IME UID 实际获得 120 Hz override。动画静止后，该 override 消失并回到系统默认调度。用户真机主观验收为「明显更流畅」，未发现 `VerifyError`、应用崩溃或异常退出。

## 构建与兼容范围

完整构建继续通过：

- 从固定原始 APK 开始的可复现补丁与 Compose Material 3 Host 重建
- 6,633 个旧公开资源 ID 保持
- API 31、33、34、35、36 静态门禁
- legacy primary DEX 与 API 36-only 调用隔离
- Header Platform、Inline Autofill 和敏感 Clipboard 门禁
- APK v1/v2/v3 签名与 16 KiB ZIP alignment

兼容边界：

- 动态高刷提示仅在 Android 16/API 36 及以上生效，Android 15 及以下行为不变。
- 系统可因省电模式、温度、设备刷新率能力或厂商策略降低或拒绝高刷请求。
- APK 仅提供 `arm64-v8a` 架构。
