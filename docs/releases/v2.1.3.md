本版本把成对标点自动补全扩展到英文键盘，并补全符号页上此前遗漏的装饰性与兼容性括号、引号。中文键盘与英文键盘共用同一张开闭符号表和同一个开关，行为一致。Google 拼音原有的输入、候选、学习、手写、主题和分页行为保持不变。

## 主要更新

- **英文键盘支持自动补全成对标点**：`( [ { <` 输入后自动补上右半边，光标落在两者之间。英文键盘不读取处理器链，补全改由 IME 子类在 `handle` 之前调用共享钩子完成，`ime_en_9key.xml` 只把 IME 类指向兼容类，不新增键盘布局。
- **补全装饰性与兼容性括号、引号**：把 `❨❩ ❲❳ ❴❵ 〘〙 ︵︶ ︷︸ ︹︺ ︻︼ ︽︾ ︿﹀ ﹁﹂「」『』 "" «» ‹› ❛❜ ❝❞` 等符号页上已有的成对符号纳入同一张开闭符号表。
- **补全后成对删除**：光标停在成对符号之间时，按一次退格会同时删掉左右两半，不会留下孤立的半字符。
- **开关位置与默认值不变**：补全开关仍默认开启，位于「设置 → 输入设置」中双空格句号开关的下方，中文与英文键盘由同一个开关控制。

## 已知行为说明

英文键盘上，符号属于原版解码器的词分隔符集合，符号之后会保留一次下一词建议。此时按第一次退格只退出这次建议，删掉刚补全的一对符号需要按两次退格。这是原版 Google 拼音输入法就有的行为，本版本没有改动它。

保留理由：要消除它需要收窄喂给原生解码器的词分隔符集合，那会连带改变自动空格、自动大写和句子结束符判定，或者改解码器内部的退格判据 `adw.a(JLchw;)Z`。两者都超出「修复已定位缺陷」的范围，因此本版本如实说明，由用户自行判断是否开启补全。
