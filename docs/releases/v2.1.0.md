本版本新增 Rime 用户词典双向同步，并重做用户词库状态的展示方式。手动与自动两个入口共用同一套执行、恢复和安全校验逻辑。Google 拼音原有的输入、候选、学习、手写、主题和分页行为保持不变，用户词典格式与此前的备份、导入语义也没有改变。

## 主要更新

- **Rime 用户词典同步**：在「词典与备份」页面新增「Rime 同步」区域，可以配置同步目录、本设备名称和 Rime 用户词典文件名。同步目录通过 Storage Access Framework 授权，可以是本地存储、SD 卡或云端文档目录。
- **手动与自动共用一套逻辑**：正常路径点击一次即可完成读取、规划、执行和收尾，只有首次接受处理规则或涉及删除时才需要确认。自动同步默认关闭，开启后按所选间隔在后台处理词条的新增、删除和重新添加。
- **只同步词条存在性**：以各设备同名的 Rime 用户词典快照为依据，只处理多字词条的存在与删除，不换算历史词频，也不改写 Rime 的词频记录。
- **安全处理不兼容词条**：暂时无法由 Google 拼音直接接收的词条会保留在 Rime，既不阻塞其他词条，也不修改原编码或转写英文用户词典。
- **目录迁移延续同步关系**：更换同步目录时会在确认数据归属后延续原有的设备身份、盐、基线和保留标记，迁移完整合法的原有数据不需要删除任何设备文件夹。
- **可中断后续处理**：普通系统中断、后台任务被停止或文件暂时无法读取时，应用会保留继续处理所需的状态并在之后重试，不要求用户手动恢复。
- **重做用户词库状态**：状态区改用颜色和文字共同表示健康状态，分为「可正常读取」「需要注意」和「暂时无法确认」。折叠状态只在对应的自动开关开启时显示摘要，展开后显示上次成功同步的双方共有和仅保留在 Rime 的数量。
