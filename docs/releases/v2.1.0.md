# Google 拼音输入法 2.1.0

本版本新增 Rime 用户词典双向同步，并重做用户词库状态的展示方式。手动与自动两个入口共用同一套执行、恢复和安全校验逻辑。Google 拼音原有的输入、候选、学习、手写、主题和分页行为保持不变，用户词典格式与此前的备份、导入语义也没有改变。

## 主要更新

### Rime 用户词典同步

- 在「词典与备份」页面新增「Rime 同步」区域，可以配置同步目录、本设备名称和 Rime 用户词典文件名。同步目录通过 Storage Access Framework 授权，可以是本地存储、SD 卡或云端文档目录。
- 手动「立即同步」与自动同步共用同一套逻辑。正常路径点击一次即可完成读取、规划、执行和收尾，只有首次接受处理规则或涉及删除时才需要确认。
- 自动同步默认关闭。开启后按所选间隔在后台处理词条的新增、删除和重新添加，默认 24 小时，可选 6 小时、12 小时、24 小时、2 天、3 天和 7 天。执行时机由系统后台调度安排，可能晚于所选间隔。
- 同步以各设备同名的 Rime 用户词典快照为依据，只处理多字词条的存在与删除，不换算历史词频，也不改写 Rime 的词频记录。
- 暂时无法由 Google 拼音直接接收的词条会保留在 Rime，既不阻塞其他词条，也不修改原编码或转写英文用户词典。
- 更换同步目录时会在确认数据归属后延续原有的设备身份、盐、基线和保留标记。迁移完整合法的原有数据不需要删除任何设备文件夹。
- 普通系统中断、后台任务被停止或文件暂时无法读取时，应用会保留继续处理所需的状态并在之后重试，不要求用户手动恢复。

### 用户词库状态

- 词库状态区改用颜色和文字共同表示健康状态，分为「可正常读取」「需要注意」和「暂时无法确认」。颜色只作辅助，不让颜色成为唯一提示。
- 折叠状态只在对应的自动开关开启时显示摘要，包括自动备份和 Rime 同步的上次成功时间。
- 展开状态显示「上次成功同步：双方共有 N 条，仅保留在 Rime 的有 M 条」，数量来自已提交的同步基线，不再用原生权重之和冒充词条数。
- 词库是否可读取改由词库接口本身判断，「展开详情」和「重新检查」各自独立，展开与收起带过渡动画。

## 使用说明

1. 打开「设置 → 词典与备份」，展开「当前用户词库状态」可以查看词库健康和同步统计。
2. 在「Rime 同步」中选择同步目录，然后填写本设备名称和 Rime 用户词典文件名。
3. 点击「立即同步」完成第一次同步。首次会遇到一次处理规则说明，确认后应用按同一规则处理后续条目。
4. 需要自动同步时打开「自动同步」开关并选择间隔，开启说明会指出同步包含删除行为。

## 真机验收

Pixel 10 Pro / Android 16 使用隔离审计包完成端到端回归，随后以正式签名、非 Debug 的体验包覆盖安装并连续使用约七天：

- 手动与自动同步共用同一入口，正常路径一次点击完成，涉及删除时才出现确认
- 真实后台任务完成词条的新增、删除和重新添加，事务结束后五项预览变更均为零
- 更换同步目录并复制原有内容后同步成功，身份、盐、基线和自动开关都保持不变
- 运行期间换入外来身份会被识别并暂停，还原后可以通过「立即同步」恢复
- 七天复核时三方快照已经收敛，本机快照与同步基线逐条一致，删除传播在设备之间一致
- 状态库保持空闲，没有待执行事务，系统作业最近一次成功运行没有失败记录
- 没有崩溃或 ANR 记录，同步目录里没有残留的临时文件或外来身份文件

## 构建与兼容范围

完整构建继续通过：

- 从固定原始 APK 开始的可复现补丁与 Compose Material 3 Host 重建
- 6,633 个旧公开资源 ID 保持
- API 31、33、34、35、36 静态门禁
- Header Platform、Inline Autofill、敏感 Clipboard 和简繁切换门禁
- Candidate 与符号分页帧率门禁
- 符号分页 settle、滚动触摸和键盘切换动画门禁
- Rime 同步协议、状态存储、SAF 和 Native Bridge 门禁
- Compose 状态与业务契约测试
- APK v1/v2/v3 签名与 16 KiB ZIP alignment
- 正式 APK 非 Debuggable

兼容边界：

- Rime 同步设置位于 Android 15/API 35 及以上的现代设置界面。Android 14 及以下的旧设置页继续提供词典状态与自动备份，不显示该入口。
- 自动同步依赖系统 JobScheduler，从 Android 5.0/API 21 起可用，开启后仍受系统后台调度限制。
- API 17–29 的旧 ART 运行时仍受当前 ARM64 ABI 和模拟环境限制，继续保持静态隔离结论，不描述为真机运行时验收。
- TalkBack Inline Suggestions 独立验收尚未完成，因此继续不声明 `supportsInlineSuggestionsWithTouchExploration`。
- APK 仅提供 `arm64-v8a` 架构。
