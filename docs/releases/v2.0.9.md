# Google 拼音输入法 2.0.9

本版本修复拼音组合文本在部分选词后轻微增高的问题，并将软件内入口和项目首页更新到重命名后的 GitHub 仓库。修复只影响拼音组合文本浮层的行高计算，不改变 Candidate、输入提交、学习或其他文本视图。

## 主要更新

- **保持拼音组合文本高度稳定**：提高 target SDK 后，`TextView` 默认会让实际使用的 fallback font 参与行高计算。纯拉丁字母组合文本在部分选词后变为中英文混排时，浮层可能因此轻微增高。本版本只在 `composing_text.xml` 中设置 `android:fallbackLineSpacing="false"`，恢复原版紧凑行高。
- **限制修复范围**：新增静态门禁，要求 `fallbackLineSpacing` 覆盖只能出现一次，并且只能位于拼音组合文本布局。Candidate、普通输入框和其他 `TextView` 继续使用原有行为。
- **保留低版本资源回退**：最终 APK 同时包含不使用新属性的基础布局，以及包含该覆盖的版本化布局。API 17–21 继续使用原有基础资源。
- **更新仓库地址**：README 和 API 35+ 设置「关于」页面中的项目入口已更新为 [ComebackGooglePinyinInput](https://github.com/huaxianyan/ComebackGooglePinyinInput)。

## 真机验收

Pixel 10 Pro / Android 16 使用隔离、`release-like`、非 Debug 审计包完成验证：

```text
输入：zhe'yang'bu'xing
部分选词：这样
剩余组合文本：这样bu'xing

组合文本浮层高度：稳定
中文和拉丁字符：无上下裁切
审计输入法进程：保持存活
审计包对应的 crash buffer 条目：0
```

测试结束后已恢复正式输入法，卸载审计包并删除一次性签名材料。正式应用数据和首次引导状态没有改变。

## 构建与兼容范围

完整构建继续通过：

- 从固定原始 APK 开始的可复现补丁与 Compose Material 3 Host 重建
- 6,633 个旧公开资源 ID 保持
- API 31、33、34、35、36 静态门禁
- API 17–29 不解析 API 30 Inline Autofill 类
- API 17–35 不解析 API 36 帧率方法
- Header Platform、Inline Autofill、敏感 Clipboard 和简繁切换门禁
- Candidate 与符号分页帧率门禁
- 符号分页 settle 门禁
- Compose 状态与业务契约测试
- APK v1/v2/v3 签名与 16 KiB ZIP alignment
- 正式 APK 非 Debuggable

兼容边界：

- API 17–29 的旧 ART 运行时仍受当前 ARM64 ABI 和模拟环境限制，继续保持静态隔离结论，不描述为真机运行时验收。
- TalkBack Inline Suggestions 独立验收尚未完成，因此继续不声明 `supportsInlineSuggestionsWithTouchExploration`。
- APK 仅提供 `arm64-v8a` 架构。
