# Google 拼音输入法 2.0.1

本版本主要为 Android 15 及更高版本引入源码构建的官方 Compose Material 3 设置运行时，并建立浅色、深色和固定模式相互独立的键盘主题槽。Android 14 及更低版本继续使用原生旧版 Preference 设置，原有输入、候选、学习、词典、手写、主题和备份语义保持不变。

## 主要更新

- **官方 Compose Material 3 设置**：API 35+ 使用官方 Material 3 组件，提供分层设置首页、类型化开关、列表和 Slider、页面转场、动态配色以及可保存的导航状态。
- **低版本严格隔离**：API 17–34 继续使用旧 Preference UI、键值、默认值、依赖和业务回调，旧 ART 启动路径不会解析 Compose 或 AndroidX 类型。
- **现代词典操作**：在 Compose 词典页内整合 SAF 备份列表、合并导入、联系人建议授权和带随机确认码的清除用户词典流程，同时继续复用原生词典任务和格式。
- **独立主题槽**：浅色、深色和固定模式分别保存完整主题规格。跟随系统时只选择对应槽位，不覆盖未激活槽，也不替用户重新分类主题。
- **反馈与可访问性**：按键音量和振动时长使用直接调整、释放后提交和预览的 Material 3 Slider，并覆盖 TalkBack、RTL、大字体、窄屏、横屏和分屏场景。
- **可复现现代 Host**：正式构建保留全部 6,633 个旧资源 ID、primary DEX 和原生载荷，并持续验证 API 31/33/34/35/36、v1/v2/v3 签名和 16 KiB ZIP alignment。
