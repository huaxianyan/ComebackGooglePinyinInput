本版本把 Rime 用户词典同步的完整设置补到旧设置页，API 17 至 34 上不再只有现代设置页能配置。8 个条目复用现代设置页同一套门面，同步行为、自动同步结果与删除确认完全一致，Google 拼音原有的输入、候选、学习、手写、主题和分页行为保持不变。

## 主要更新

- **旧设置页新增 Rime 同步区域**：在「设置 → 词典与备份 → 用户词典」下新增 8 项，分别是同步状态、同步目录、设备名、Rime 用户词典文件、自动同步、自动同步间隔、立即同步和重新建立同步状态。
- **状态不再只读**：未配置时状态项提示点击选择同步目录，配置完成后显示上次成功时间与双方词条计数，不必再依赖现代设置页查看。
- **目录与命名可配**：同步目录经 Storage Access Framework 授权，请求与现代设置页相同的可持久读写权限，替换目录时释放旧目录的权限，并标注内部存储或 SD 卡。
- **就地校验**：设备名必须能作为目录名，Rime 用户词典文件名必须以 `.userdb.txt` 结尾，不合法时对话框不关闭，不会拖到同步时才失败。
- **自动同步可开关**：自动同步开关与间隔可从旧设置页驱动，间隔列表由引擎契约生成，早期通过滑块写入的值仍然可选。
- **立即同步**：走与现代设置页相同的手续，词条处理规则确认一次，涉及删除时先显示双方增删计数。
- **失败原因分开说明**：每个失败码对应自己的文案，Rime 词典不可读、计划在预览后变化、用户词典写满等情况都能直接在页面上看到。

配置与操作全部写入同一个门面，两处设置页不会各自保存偏好，旧页显示的也是调度器实际接受的结果。

使用方式见 [README 的 Rime 用户词典同步](https://github.com/huaxianyan/ComebackGooglePinyinInput/blob/v2.1.2/README.md#rime-用户词典同步)，完整实现与验收记录见 [CHANGELOG 2.1.2](https://github.com/huaxianyan/ComebackGooglePinyinInput/blob/v2.1.2/CHANGELOG.md#212---2026-09-27)。
