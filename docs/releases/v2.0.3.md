Android 11 起支持键盘内 Inline Autofill，并统一建议与剪贴板候选的切换。

## 新功能

- **Inline Autofill**：键盘显示系统及 Autofill Provider 提供的建议，由系统完成认证与填充。
- **项目仓库入口**：现代设置的「其他 → 关于」增加 GitHub 仓库链接。

## 问题修复

- **首次布局**：修正主题或方向切换后建议区域的首次布局。

## 改进

- **建议切换**：关闭或提交剪贴板候选后，恢复仍有效的 Autofill 建议。

完整更新与验证边界见 [CHANGELOG 2.0.3](https://github.com/huaxianyan/ComebackGooglePinyinInput/blob/v2.0.3/CHANGELOG.md#203---2026-08-13)。
