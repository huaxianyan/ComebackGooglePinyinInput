# Google 拼音输入法 2.0.3

本版本在保留原生输入、候选、学习、词典、手写、主题和备份语义的前提下，为 Android 11 及以上版本加入标准 Inline Autofill，并将原生 Candidate、Clipboard 与 Autofill 收敛到统一 Header Platform。

## 主要更新

- **标准 Inline Autofill**：直接托管 Android Framework / Autofill Provider 提供的远端 `InlineContentView`，由系统完成认证和填充。输入法不读取凭据正文、不转换为 Candidate，也不自行提交 Autofill payload。
- **统一 Header Platform**：原生 Candidate、Clipboard quick-paste Candidate 和 Inline Autofill 使用集中会话、Header identity、render generation、仲裁、主题、无障碍与清理契约，同时保留各自正确的数据与点击链路。
- **稳定的建议切换**：Inline Autofill 使用一个可见项目和原生上一项/下一项 rails。Clipboard 临时接管后，关闭或提交时自动恢复仍有效的 Inline 建议。
- **原生视觉一致性**：Clipboard 与 Autofill rails 复用真实运行时 Candidate divider、方向图标和主题输出，并修复主题或方向切换后的首次布局。
- **安全的 Surface 生命周期**：远端建议按 editor、Header 和 render generation 拒绝过期回调，并使用 View-local 坐标显式裁剪。Inactive Surface 不可见、不可交互，也不参与无障碍。
- **设置仓库入口**：API 35+ Compose Material 3 设置的「其他 → 关于」页面增加项目 GitHub 仓库地址，API 17–34 继续使用旧设置路径。
- **文档整理**：README 重构为简洁项目首页，原始 APK 来源、构建、GitHub Actions、签名和发布细节迁移到独立文档。

## 兼容边界

- Inline Autofill 需要 Android 11/API 30 及以上，并取决于 App、Android Autofill Framework 和用户选择的 Autofill Provider。
- Android 15/API 35 及以上使用官方 Compose Material 3 设置，Android 14/API 34 及以下继续使用原设置界面。
- TalkBack touch exploration 下的 Inline Suggestions 尚未声明支持，系统继续使用自身回退路径。
- APK 仅提供 `arm64-v8a` 架构。
