# Google 拼音输入法 2.0.10

本版本修复键盘切换期间的两处稳定性与窗口高度问题，并修复标点、符号和 Emoji 分页手势移出区域后回弹的问题。输入、Candidate、学习、词典、手写识别和既有分页目标语义保持不变。

## 主要更新

- **避免键盘切换时崩溃**：Android 15 切换到尚未完成测量的手写等键盘时，不再使用 0 宽高计算动画。此时会直接完成切换，尺寸正常时仍保留原有动画。
- **保持密码输入框切换高度稳定**：普通输入框切换期间即使短暂显示缓存的密码键盘内容，也不会错误增加额外的 Header 高度。文本密码键盘继续保留 Autofill Header 和数字快捷行。
- **保持区域外松手分页**：标点、符号和 Emoji 横向分页时，手指移出分页区域再松开，分页 View 仍能收到完整手势，不再回弹到当前页。外层按键事件会独立取消，避免恢复松手误选。
- **保持原有分页手感**：paging touch slop、fling、速度判断、12.5% settle 和目标页计算均未改变。

感谢 [hursandqwq](https://github.com/hursandqwq) 提交并协助完善这些修复。

## 真机验收

Pixel 10 Pro / Android 16 使用隔离、`release-like`、非 Debug 审计包完成验证：

- Telegram X 等密码输入框与普通输入框之间切换时，输入法窗口高度保持稳定
- 切换到尚未完成测量的手写等键盘时不再崩溃，正常尺寸的切换动画保持
- 标点、符号、Emoji 和展开候选分页的普通点击、区域外松手、左右边界、快速 fling 和轻拖均正常
- 未发现分页回弹、误选、按键状态卡住或目标页变化
- 审计进程保持存活，crash buffer 中没有匹配审计包的条目

测试结束后已恢复正式输入法并卸载审计包。正式应用数据和首次引导状态没有改变。

## 构建与兼容范围

完整构建继续通过：

- 从固定原始 APK 开始的可复现补丁与 Compose Material 3 Host 重建
- 6,633 个旧公开资源 ID 保持
- API 31、33、34、35、36 静态门禁
- API 17–29 不解析 API 30 Inline Autofill 类
- API 17–35 不解析 API 36 帧率方法
- Header Platform、Inline Autofill、敏感 Clipboard 和简繁切换门禁
- Candidate 与符号分页帧率门禁
- 符号分页 settle、滚动触摸和键盘切换动画门禁
- Compose 状态与业务契约测试
- APK v1/v2/v3 签名与 16 KiB ZIP alignment
- 正式 APK 非 Debuggable

兼容边界：

- API 17–29 的旧 ART 运行时仍受当前 ARM64 ABI 和模拟环境限制，继续保持静态隔离结论，不描述为真机运行时验收。
- TalkBack Inline Suggestions 独立验收尚未完成，因此继续不声明 `supportsInlineSuggestionsWithTouchExploration`。
- APK 仅提供 `arm64-v8a` 架构。
